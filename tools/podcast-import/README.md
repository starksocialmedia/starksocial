# Podcast import — live → Phase 2

37 published episodes of The Social Life Podcast (first run November 2 2026).

1. **Episodes**: same flow as `tools/blog-snapshot/` with `--post_type=podcast`
   (export with `--skip-themes`, stream over ssh, `register-attachments.php`,
   `wp import --skip=attachment --authors=authors.csv`, then
   `strip-cornerstone.php apply type=podcast` — 6 episodes had a "Download Full
   Show Transcript" PDF button, kept as a link).
2. **Podlove data** (only needed while Podlove is NOT installed): on live, dump
   `podlove_episode` + active `podlove_mediafile` rows to JSON (number, subtitle,
   duration, slug → `media_file_base_uri` + slug + extension), fetch each
   episode's transcript `.txt` from podcast.starksocial.com into
   `transcript_text`, then:
   `STARK_JSON=podlove.json wp eval-file tools/podcast-import/seed-podcast-meta.php`
   → post meta `episode_number`, `episode_duration`, `episode_subtitle`,
   `episode_audio_url`, `episode_transcript`.

**At launch, install + activate Podlove Podcasting and Podlove Web Player and
migrate their tables** — the podcast RSS feed (`/feed/podcast/`, used by Apple
Podcasts) is generated by Podlove. With Podlove active, the templates use its
web player and `[starkpodmeta]` reads its tables automatically.
